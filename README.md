# Student Management System 📚

A simple **Student Management System** built using Python.
This project allows users to add, view, search, update, and delete student records using a JSON file for data storage.

## 🚀 Features

* ➕ Add Student
* 👀 View All Students
* 🔍 Search Student by Name
* ✏️ Update Student Details
* 🗑️ Delete Student
* 📊 Calculate Average Marks
* 🏆 Find Top Student
* 💾 Store data permanently using JSON
* 🆔 Automatic Student ID Generation

## 🛠️ Technologies Used

* Python
* JSON
* File Handling
* Dictionaries
* Loops & Conditional Statements
* Exception Handling
* `datetime` module

## 💾 Data Storage

Student records are stored in `students.json`.

Example:

```json
{
    "100": {
        "student_name": "Rahul",
        "student_age": 20,
        "student_course": "Python",
        "student_marks": 85,
        "date": "20-08-2026"
    }
}
```
